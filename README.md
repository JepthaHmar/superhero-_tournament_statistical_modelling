# Statistical Modelling of the Ultimate Superhero Tournament

**Can statistics settle fan debates?** — Group project, Statistical Learning Models using R, MBA (Analytics) 2025–27, IIM Kashipur

## Problem
Superhero "who would win" debates are driven by fan bias and recency. Character profiles, however, carry measurable attributes (Intelligence, Strength, Speed, Durability, Power, Combat). This project builds a data-driven 16-player tournament to estimate win probabilities and identify what actually drives a hero's chances.

## Data
- **Source:** Superheroes NLP Dataset (Kaggle), scraped from SuperHeroDB. The copy in `data/` is the public version distributed with the open-source texthero project
- Included file: 1,450 raw records → **975 cleaned Marvel & DC profiles** (duplicates and incomplete records removed)
- 6 standardised ability predictors: Intelligence, Strength, Speed, Durability, Power, Combat
- The presentation was built on a slightly different scrape (1,471 rows → 958 profiles), so script output differs from the slides by about one percentage point or less

## Methodology
| Step | Technique | Purpose |
|---|---|---|
| Dimensionality reduction | **PCA** | Built a composite Ability Index (PC1 = 50.4% of variance; driven by Durability, Strength, Speed) |
| Exploratory profiling | **K-Means** (k = 3, silhouette-guided) | Cosmic Powerhouses, Street-Level/Skill-Based, Mid-Tier Specialists |
| Matchup model | **Logistic Regression (binomial GLM)** | Pairwise win probabilities from ability differences |
| Tournament simulation | **Markov chain transitions** | Propagated survival odds from Round of 16 → Champion, enforcing P(B wins) = 1 − P(A wins) |
| Sensitivity analysis | What-if entrant | Tested the ability threshold a new balanced hero needs to compete |

## Key Findings
- **Intelligence** had the strongest positive effect on win probability; Combat showed a slight negative coefficient once power and intelligence were controlled for (the "Combat Paradox")
- **Cosmic King Thor** was the modelled champion at **13.8%** odds, despite not being the highest-ability character, because of a favourable bracket seed
- Aggregated by publisher, **Marvel held 70.2%** of championship probability vs DC's 29.8% (an artefact of bracket composition, not a canonical claim)
- A perfectly balanced new hero needs **100/100 in every ability** just to make the top 16, at which point they become the favourite (14.7%)

## Future Work
Replace proxy win targets with real battle records, and run Monte Carlo bracket shuffles to separate raw power from seeding luck.

## How to Run
1. Clone or download this repository. The dataset is already included in `data/`.
2. From the repository root, run `Rscript superhero_tournament.R`, or open it in RStudio with the working directory set to the repo folder and `source()` it.

Only base R and the `cluster` package (bundled with R) are needed. Plots are written to `tournament_outputs/`. Exact figures can differ slightly between versions of the scraped dataset.

## Tech Stack
R · `prcomp` (PCA) · `kmeans` + `cluster::silhouette` · `glm` (binomial) · Markov chain bracket propagation · base R graphics
